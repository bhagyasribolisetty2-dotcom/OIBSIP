
# Kalpana — Beyond the Sky

## Oasis Infobyte Internship

- **Track:** Web Development and Designing
- **Level:** 2
- **Task:** 2 — Tribute Page
- **Project Name:** Kalpana — Beyond the Sky

## Project Overview

Kalpana — Beyond the Sky is an interactive tribute website dedicated to Kalpana Chawla, the first woman of Indian origin to travel into space.

The website presents her inspiring journey from Karnal, Haryana, to becoming a NASA astronaut through cinematic visuals, moving animations, photographs and interactive storytelling.

The central theme of the website is imagination turned into reality.

## Features

- Cinematic space-themed homepage
- Animated stars and moving particles
- Interactive spaceship launch animation
- Smooth scrolling and page transitions
- Interactive flashlight portrait reveal
- Childhood and family information
- Animated educational and career timeline
- NASA space mission information
- Interactive constellation
- Inspirational quotes
- Achievements and legacy section
- Space Shuttle Columbia crew memorial
- Interactive visitor tribute section
- Responsive website design

## How to Run the Project

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to public/tribute/index.html.
4. Open index.html in a web browser or use Live Server.
5. Explore the website and its interactive animations.
