## Project Overview

TaskVerse is a customizable personal productivity web application that combines a to-do list, recurring weekly timetable planner, digital notebook, personal diary, calendar, reminders and productivity analytics into a single workspace.

Unlike a traditional to-do list, TaskVerse allows users to create personalized weekly schedules with starting and ending dates. Scheduled activities automatically appear in the daily to-do list, while users can manually add additional tasks, reminders and important deadlines.

The application features a modern lavender and white interface with sage green highlights, customizable themes, smooth animations and responsive layouts.

## Application Workflow

1. Open the TaskVerse dashboard.
2. Create a personalized weekly timetable.
3. Select the starting and ending dates.
4. Customize activities for each weekday.
5. Save the timetable.
6. View automatically generated daily activities.
7. Add additional tasks and reminders.
8. Mark completed activities.
9. Review daily, weekly and monthly progress.
10. Continue the routine until the timetable ends.

## Data Storage and Privacy

TaskVerse uses the browser's LocalStorage API to store:

- Weekly timetables
- Daily tasks
- Completion records
- Notes and diary entries
- Theme preferences
- Profile information

Data remains available in the same browser after refreshing or reopening the website, provided browser storage has not been cleared.

The application does not currently provide cloud synchronization, user authentication or encrypted diary storage.

Users can export and import JSON backups to protect their information.

Historical statistics may change when certain existing activities are edited or deleted.

Timed reminders require the application to remain open.
