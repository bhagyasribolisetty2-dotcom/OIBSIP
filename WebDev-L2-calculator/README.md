
# CalcVerse - Luxury Scientific Calculator

## Internship Details

- Organization: Oasis Infobyte
- Domain: Web Development & Designing
- Level: 2
- Task: 1 - Calculator

## Project Description

CalcVerse is an interactive scientific calculator
website developed using HTML, CSS and Vanilla
JavaScript.

It features a premium Luxury Black and Gold
interface with animated backgrounds, metallic
buttons and interactive 3D effects.

## Features

- Basic arithmetic operations
- Scientific mathematical operations
- Trigonometric functions
- Degree and Radian modes
- Square root and cube root
- Logarithmic functions
- Factorial and percentage calculations
- Operator precedence
- Clear and delete functionality
- Division-by-zero error handling
- Keyboard support
- Responsive user interface
- Interactive 3D animations
- Animated landing page

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Grid
- CSS Animations

## Project Structure

- index.html - Landing page
- style.css - Landing page styling
- script.js - Landing page interactions
- calculator.html - Scientific calculator
- calculator.css - Calculator styling
- calculator.js - Mathematical operations

## How to Run

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open index.html using Live Server.
4. Click Start Calculating.
5. Enter an expression and press equals.
